# Судпомощник — sud-pomoshnik.ru

Статический сайт без зависимостей (Node.js ≥ 20). Собрано по этапам 4 и 5 вашего ТЗ.

## Что внутри

- `dist/` — **готовый собранный сайт** (29 страниц, sitemap, robots.txt, llms.txt, CNAME). Его можно выкладывать как есть.
- `content/*.md` — тексты страниц (правите здесь). `data/courts.json` — суды и районы. `data/site.json` — телефон, автор, дата сверки норм.
- `build.mjs` — сборка. `scripts/check.mjs` — проверка (метатеги, H1, canonical, битые ссылки, sitemap). `scripts/serve.mjs` — просмотр на `localhost:8080`.
- `.github/workflows/deploy.yml` — выкладка на GitHub Pages (временный вариант, как в разделе 14 этапа 4). `deploy/` — nginx и выкладка на VPS для переезда.

## Команды

    npm test          # собрать и проверить
    npm run build     # только собрать
    npm run serve     # посмотреть на http://localhost:8080

## Запуск на GitHub Pages

1. Залейте содержимое папки в репозиторий (ветка `main`).
2. Settings → Pages → Source: GitHub Actions; Custom domain: `sud-pomoshnik.ru`; Enforce HTTPS.
3. Приватный репозиторий: Pages на бесплатном тарифе недоступен (см. раздел 14 этапа 4).

## Что НЕ сделано и почему (заполните до запуска)

| Что | Почему |
|---|---|
| Адреса, телефоны, часы приёма судов и мировых участков | В загруженных файлах их нет, а надёжно найти в открытых источниках не удалось. Выдумывать не стал. Впишите в `data/courts.json` поля `address` и `phone`: они появятся на страницах судов |
| Блоки «практика автора», «шаги работы», фото, ИНН | Нужны ответы на анкету этапа 5 и ваши данные. По правилам плана такие блоки не пишутся без данных |
| Цена именно за возражения на приказ | В тексте везде общий диапазон 5 000–10 000 ₽ из плана. Если цена отдельная, поправьте `content/uslugi-prikaz.md` и `content/ceny.md` |
| Раздел кейсов `/keysy/` | Решение владельца от 13.11.2026: кейсы не публикуются |
| Формы, «Автоюрист» | Отложено до своего сервера и юридической проверки (раздел 14 этапа 4) |
| Цели Метрики Telegram и ВК, скачивание образцов | Нет ссылок на Telegram/ВК и файлов образцов. Работают цели `phone_click` и `calc_used` |

## Юридические нормы: что проверено

Сверено 18.11.2026 **по открытым публикациям и справочным системам**, а не по первоисточнику `pravo.gov.ru`: 10 дней на возражения (ст. 128–129 ГПК), возражения без мотивировки, порядок восстановления срока с 01.01.2026 (ФЗ от 01.04.2025 № 49-ФЗ, ст. 112 ГПК). Редакция ст. 129 от 04.08.2026 (ФЗ № 333-ФЗ, с 01.09.2026) эти правила не меняет.
Взяты из общих знаний и в источниках не открывались: срок 7 дней по ст. 237 ГПК, ч. 5.1 ст. 99 закона об исполнительном производстве, правило переноса срока на рабочий день. Сверьте их перед запуском. Вопросы поворота исполнения и прекращения исполнительного производства в текстах намеренно не раскрыты.
Политику конфиденциальности, работу Вебвизора и cookies покажите юристу (раздел 8.3 этапа 4).
